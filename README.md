Project Description

The University Student Record and Campus Route Management System is a Java-based console application developed using data structures and algorithms.

The system manages student records, service requests, recent actions and campus locations and connections.

Main Features

* Add, update and delete student records
* Display student records
* Student search using Hash Table
* Student organization and searching using Binary Search Tree
* Recent actions using Stack
* Student service requests using Queue
* Add and remove campus locations
* Add and remove campus connections
* Display campus connections
* Breadth-First Search (BFS)
* Depth-First Search (DFS)
* Input validation and error handling
* Menu-driven console interface

Data Structures Used

Linked List

Used to store and manage student records.

Stack

Used to maintain recent system actions using the Last-In-First-Out (LIFO) principle.

Queue

Used to manage student service requests using the First-In-First-Out (FIFO) principle.

Binary Search Tree

Used to organize and search student records based on Student ID.

Hash Table

Used for efficient Student ID searching.

Graph

Used to represent campus locations and the connections between them. BFS and DFS are used for campus traversal.
